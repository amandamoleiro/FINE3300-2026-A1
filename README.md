## Part D: Comparison of My Code and the LLM Code
When comparing the code I made myself in Part 1 to the code generated by OpenAI's GPT-6 through ChatGPT in Part 2, I noticed that while both programs were able to correctly convert the currencies, they had some differences in how the code was written. In Part 1, I used open (), read (), and split () to separate the CSV data in rows and columns, like what we learned in the textbook. In Part 2, the code generated by ChatGPT used Python’s csv module and DictReader (), which made reading the file more efficient.

Another difference between them was how the exchange rate was stored. In my code I used self.__rate, a private attribute, meanwhile ChatGPT used self.rate, a public attribute. Additionally, my code used .format() to show the results, while ChatGPT used an f-string. 

In conclusion, both programs were able to produce the same results for the currency conversion.  My code was longer while ChatGPT’s code was shorter and more straightforward. Comparing them helps demonstrate how there can be multiple different ways to achieve the same outcome in Python.
